# 使用说明

## 先给企业画像

第一次处理某家企业的账务时，先提供：

1. 企业名称、行业、成立时间
2. 年收入规模、从业人数、资产总额
3. 增值税纳税人类型（小规模/一般纳税人）
4. 是否有外部融资、子公司、公开市场计划
5. 会计期间、币种、金额单位
6. 现有资料：流水、发票、合同、银行对账单、工资表、折旧表

总入口会据此选择《小企业会计准则》或《企业会计准则》，再路由到具体技能。

## 常见工作流

### 1. 新建账套

```text
按小企业会计准则给这家公司建账：
- 行业：软件研发
- 年收入：0
- 纳税人：小规模
- 现有资料：银行流水、房租合同、工资表
```

路由：`accounting-framework` → `chart-of-accounts` → `journal-entry` → `month-end-close`

### 2. 日常记账

```text
把这 10 笔银行流水和 3 张发票做成记账凭证，借贷必须平，附件编号对应。
```

路由：`journal-entry`，必要时参考 `vat-accounting`

### 3. 月末结账和报表

```text
做 6 月月末结账，计提房租和工资，结转损益，然后出资产负债表和利润表。
```

路由：`month-end-close` → `balance-sheet` / `profit-loss` / `cash-flow`

### 4. 税务计算

```text
小规模纳税人，二季度含税收入 28 万，增值税和附加税怎么算？需要预缴企业所得税吗？
```

路由：`vat-accounting` → `tax-rates-reference` → `income-tax`

### 5. 审计项目

```text
对这家公司做年度审计，先评估风险、算重要性，再做应收账款和收入实质性程序，最后出审计报告。
```

路由：`audit-master` → `risk-assessment` → `materiality` → `receivables-audit` / `revenue-audit` → `audit-adjustments` → `audit-report`

## 输出约定

- **记账凭证**：日期、摘要、科目编码与名称、借方、贷方、附件、凭证号
- **报表**：项目、本期数、上期数、变动、备注
- **税务**：税种、计税依据、税率/征收率、应纳税额、申报期
- **审计**：程序、样本、发现、结论、调整建议、证据索引
- 每次输出结尾列出：采用的准则、关键假设、待补资料、需复核事项

## 会计总账模板

`templates/accounting-ledger.md` 是空白模板。复制到工作区：

```bash
cp templates/accounting-ledger.md ~/.openclaw/workspace/memory/accounting-ledger.md
```

它用于跨会话保存企业档案、历史凭证、报表快照、税务记录和审计项目。**不要提交到版本库或公开分享。**

## 免责声明

本技能包是知识参考，不构成会计、税务或审计鉴证意见。税率、准则和优惠政策以财政部、国家税务总局等官方最新文件为准；申报和审计结论请由 CPA、税务师或审计师复核。
