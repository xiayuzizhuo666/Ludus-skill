# 中国会计准则财务总入口

本技能不直接给出会计答案，而是先判断企业适用哪套准则，再把任务路由到对应的 `china-*` 子技能。

## 适用场景

- 建账、记账、编制凭证、月末结账
- 资产负债表、利润表、现金流量表、盈利分析
- 增值税、企业所得税、个人所得税、税率速查
- 审计总控、风险评估、重要性、各科目实质性程序、审计调整、审计报告

## 第一步：确认企业画像

在给方案前，先确认以下信息；缺失就问，不要猜：

| 项目 | 为什么需要 |
|---|---|
| 企业规模 / 年收入 | 判断小企业会计准则还是企业会计准则 |
| 增值税纳税人类型 | 小规模 vs 一般纳税人，决定税额处理 |
| 是否公开市场 / 有外部融资 / 有子公司 | 影响合并报表和准则选择 |
| 会计期间、币种、金额单位 | 保证报表口径一致 |
| 现有资料 | 流水、发票、合同、银行对账单、工资表、折旧表 |

准则判断读：`../china-accounting-framework/SKILL.md`

## 执行规则

1. **先定准则**：小企业会计准则和企业会计准则不能混用；先读 `accounting-framework` 的判断结果。
2. **先读子技能**：执行具体任务前读取对应 `SKILL.md`，不要凭记忆编造科目、税率或审计程序。
3. **数据来源可追溯**：金额、期间、科目必须来自用户提供的流水、发票、合同、银行对账单或工资表；缺数据就列清单让用户补。
4. **记账必平**：每张凭证借贷必须相等；摘要、附件、凭证号、日期齐全。
5. **报表必勾稽**：
   - 资产 = 负债 + 所有者权益
   - 利润表净利润与资产负债表未分配利润变动勾稽
   - 现金流量表现金净增加额与现金余额变动勾稽
6. **税务看身份**：先确认小规模/一般纳税人，再谈进项抵扣、征收率、优惠和申报周期。
7. **审计讲证据**：风险评估 → 重要性 → 实质性程序 → 调整 → 报告；不伪造函证、监盘或审计证据。
8. **政策有版本**：税率、优惠和准则以最新官方文件为准；不确定时明确标注“需复核”。

## 输出格式

- 记账凭证：日期、摘要、科目编码与名称、借方金额、贷方金额、附件、凭证号
- 报表：项目、本期数、上期数、变动、备注
- 税务：税种、计税依据、税率/征收率、应纳税额、申报期
- 审计：程序、样本、发现、结论、调整建议、证据索引

每次输出结尾列出：

- 采用的准则和口径
- 关键假设
- 待补资料
- 需要 CPA / 税务师复核的事项

## 数据连续性

如果工作区存在 `memory/accounting-ledger.md`，先读它了解企业档案、历史分录和报表快照；只有用户确认后才更新。不要在无关对话中暴露企业敏感财务信息。

## 安全与免责声明

- 不编造金额、税率、政策条款、审计证据或报表数字。
- 税务申报和审计意见必须由持证专业人士复核。
- 不自动报税、不自动出具审计报告、不自动对外发送财务数据。
- 本技能包是知识参考，不构成会计、税务或审计鉴证意见。
