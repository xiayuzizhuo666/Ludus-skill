# 七种公众号写作风格

选一种作为主风格，不要在一篇里混用太多。用户没指定时，按主题推荐一种并说明理由。

## 1. 温暖故事

- 适合：个人经历、亲情、成长、心理、生活观察。
- 结构：一个具体场景开头 → 人物遇到什么 → 转折 → 回看与感悟 → 给读者一句轻的建议。
- 句子：短句为主，允许留白；少用形容词，多用动作和细节。
- 开头：直接进入场景，不写“今天我想和大家聊聊”。
- 结尾：收回到开头的那个人或物，不喊口号。
- 禁忌：编造细节、过度煽情、把别人的伤痛当素材。

## 2. 专业干货

- 适合：方法论、行业分析、工具教程、职场技能。
- 结构：结论先行 → 3–5 个分点 → 每个分点给例子或步骤 → 常见误区 → 行动清单。
- 句子：中等长度，术语当场解释；每个判断尽量给依据。
- 开头：一句话给结论，第二段说为什么重要。
- 结尾：给一个今天就能执行的下一步。
- 禁忌：堆概念、不解释、用“显然”“众所周知”跳过论证。

## 3. 资讯日报

- 适合：一周新闻、行业动态、产品更新。
- 结构：一句总览 → 5–8 条信息 → 每条 2–3 句（发生了什么、为什么重要、来源）→ 一句编辑观察。
- 句子：短、清楚、可扫读；标题里带日期或范围。
- 开头：告诉读者今天最值得看的是哪一条。
- 结尾：不要强行升华；可以给一个继续关注的信号。
- 禁忌：把旧闻当新闻、不标来源、用情绪代替事实。

## 4. 轻松幽默

- 适合：生活吐槽、轻科普、团队文化、产品小更新。
- 结构：一个夸张但真实的场景 → 自嘲或反差 → 解释背后的道理 → 轻松收尾。
- 句子：短句、口语、节奏快；比喻要具体，不用网络烂梗。
- 开头：第一句就有画面或反差。
- 结尾：可以自嘲，不要嘲笑读者。
- 禁忌：拿弱势群体开玩笑、用冒犯换笑点、通篇只有段子没有信息。

## 5. 锐评

- 适合：热点评论、行业现象、产品体验、公共议题。
- 结构：亮明判断 → 三个理由（事实、逻辑、反例）→ 承认对方最强论点 → 给出边界或替代方案。
- 句子：短句有力，少用形容词；每个判断后面跟证据。
- 开头：第一段说清楚“我赞成/反对什么，为什么”。
- 结尾：给一个可检验的判断或下一步，不骂人。
- 禁忌：人身攻击、扣帽子、只挑软柿子、用情绪代替论证。

## 6. 人物访谈

- 适合：创业者、手艺人、研究者、一线从业者。
- 结构：人物速写 → 关键经历 → 3–5 个问答或叙事段 → 一个可复用的经验 → 结尾回到人物。
- 句子：保留受访者的语气，但删掉口头禅；引语必须真实。
- 开头：用一个具体细节让人物立起来。
- 结尾：不要替受访者总结人生；可以留一个开放问题。
- 禁忌：编造引语、把访谈写成宣传稿、只写成功不写代价。

## 7. 复盘笔记

- 适合：项目复盘、活动总结、学习记录、失败经验。
- 结构：目标 → 实际结果 → 做对了什么 → 做错了什么 → 下次怎么改 → 可复用清单。
- 句子：直接、具体；能量化的地方给数字。
- 开头：先说结果，不铺垫。
- 结尾：给一个下次可以直接照做的检查表。
- 禁忌：只报喜不报忧、把运气写成能力、用“经验丰富”代替具体做法。

## 选择建议

| 主题 | 首选 | 备选 |
|---|---|---|
| 个人经历/情感 | 温暖故事 | 复盘笔记 |
| 方法论/教程 | 专业干货 | 复盘笔记 |
| 新闻/行业动态 | 资讯日报 | 锐评 |
| 生活/轻科普 | 轻松幽默 | 温暖故事 |
| 热点/争议 | 锐评 | 专业干货 |
| 人物/品牌故事 | 人物访谈 | 温暖故事 |
| 项目/活动总结 | 复盘笔记 | 专业干货 |
