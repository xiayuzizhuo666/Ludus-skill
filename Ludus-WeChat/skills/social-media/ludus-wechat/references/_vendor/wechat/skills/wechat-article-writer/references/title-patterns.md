# 标题模式库

一次给 5–10 个选项，覆盖不同机制。每个标题都要能被正文兑现。

## 利益型

1. **动作 + 结果**：`把 X 做成 Y，只需要 Z`
   - 例：把月度报表压到半小时，只需要改三个取数习惯。
2. **省下什么**：`我用 X 方法，少花了 Y`
   - 例：我用“先写结尾”的方法，少改了三遍稿。
3. **得到什么**：`读完这篇，你会多一个 X`
   - 例：读完这篇，你会多一个判断项目该不该继续的清单。

## 好奇型

4. **具体缺口**：`X 里最容易被忽略的一步`
   - 例：合同审查里最容易被忽略的一步，不是看金额。
5. **反直觉结果**：`为什么越 X，反而越 Y`
   - 例：为什么越努力记笔记，越容易忘。
6. **未解问题**：`X 到底值不值？我算了三笔账`
   - 例：花两万块上训练营到底值不值？我算了三笔账。

## 对比型

7. **前后对比**：`从 X 到 Y，我改了哪三件事`
8. **常见做法 vs 更好做法**：`别再 X 了，试试 Y`
9. **得失对比**：`X 的好处很明显，代价也很具体`
10. **同类对比**：`A 和 B 都能 X，但适合的人不一样`

## 数字型

11. **清单**：`X 个方法 / X 个坑 / X 步`
    - 例：第一次做公众号排版，先避开这 6 个坑。
12. **时间**：`每天 X 分钟，坚持 Y 周`
13. **金额**：`预算 X 元，怎么把 Y 做好`
14. **比例**：`只有 X% 的人会注意这一步`

## 身份型

15. **点名读者**：`给 X 的一份 Y 清单`
    - 例：给第一次带团队的人一份周会清单。
16. **处境点名**：`刚 X 的人，先做这三件事`
    - 例：刚被裁的人，先做这三件事。

## 反常识型

17. **挑战默认**：`X 不是越多越好`
18. **换一个指标**：`别只看 X，先看 Y`
19. **承认边界**：`X 有用，但不适合所有人`

## 故事型

20. **一个具体的人/场景**：`那个每天提前一小时到公司的人，后来怎么样了`

## 标题自检

- [ ] 正文能兑现标题里的承诺。
- [ ] 没有“震惊”“必看”“封神”“天花板”这类空词。
- [ ] 没有编造的数字、头衔、机构。
- [ ] 读者一眼能看出“这和我有关”。
- [ ] 标题长度适合公众号列表页，通常 12–24 个汉字。
