# 文章框架模板

先给结构，等用户确认后再写全文。每个框架都写了“适合 / 不适合 / 骨架”。

## 1. 痛点-方案-证据-行动

- 适合：方法、工具、职场技能、健康科普。
- 不适合：纯故事、人物特写。
- 骨架：
  1. 痛点：一个具体场景，读者正在经历。
  2. 方案：三步以内，每步说清楚做什么。
  3. 证据：数据、案例、前后对比。
  4. 行动：今天就能做的一件小事。

## 2. 故事-冲突-转折-启示

- 适合：个人经历、成长、家庭、心理。
- 不适合：纯资讯、硬核教程。
- 骨架：
  1. 故事：人物、地点、一个具体动作。
  2. 冲突：想要的和现实的差距。
  3. 转折：一个决定、一次对话、一个发现。
  4. 启示：回到读者，给一句轻的建议。

## 3. 清单体

- 适合：工具合集、避坑、步骤、资源。
- 不适合：需要长论证的议题。
- 骨架：
  1. 一句总览：这份清单解决什么问题。
  2. 5–8 条：每条一个动作 + 一句解释 + 一个注意点。
  3. 结尾：按优先级给一个“先做哪条”。

## 4. 对比体

- 适合：方案选择、产品体验、前后变化。
- 不适合：没有可比对象的话题。
- 骨架：
  1. 两个对象/两种做法。
  2. 同一维度逐项对比：成本、时间、效果、风险。
  3. 适合谁、不适合谁。
  4. 给一个默认建议，并说明边界。

## 5. 深度长文（问题树）

- 适合：行业分析、复杂议题、政策解读。
- 不适合：短资讯、轻娱乐。
- 骨架：
  1. 核心问题：一句话说清楚。
  2. 拆成 3–5 个子问题。
  3. 每个子问题：事实 → 解释 → 反例/边界。
  4. 回到核心问题：给出判断和不确定性。
  5. 读者能带走的一个决策规则。

## 框架选择

| 主题 | 首选 | 备选 |
|---|---|---|
| 方法/工具 | 痛点-方案-证据-行动 | 清单体 |
| 个人经历 | 故事-冲突-转折-启示 | 复盘笔记 |
| 资源/避坑 | 清单体 | 对比体 |
| 选型/体验 | 对比体 | 深度长文 |
| 行业/政策 | 深度长文 | 痛点-方案-证据-行动 |
