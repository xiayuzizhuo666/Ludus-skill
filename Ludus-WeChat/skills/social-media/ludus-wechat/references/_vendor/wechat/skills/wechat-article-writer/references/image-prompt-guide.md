# 配图提示词指南

每张图只表达一个信息。提示词要具体到主体、场景、构图、光线、颜色和禁止项。

## 图片清单

| 类型 | 数量 | 尺寸 | 作用 |
|---|---|---|---|
| 封面图 | 1 | 16:9 或 2.35:1 | 列表页第一眼，决定点不点 |
| 正文信息图 | 2–3 | 1:1 或 4:3 | 每张讲清一个观点或步骤 |
| 结尾引导图 | 0–1 | 1:1 | 引导关注/收藏/留言，简洁 |

## 提示词结构

```text
主体 + 场景 + 动作/状态 + 构图 + 光线 + 颜色 + 风格 + 画幅 + 禁止项
```

示例：

```text
一位年轻职场人坐在窗边书桌前，桌上有一台笔记本电脑、一杯水和一本翻开的笔记本，
清晨侧光，浅色木质桌面，构图干净，留出右侧空白，扁平插画风格，16:9，
不要文字，不要品牌 logo，不要真实人物面部特写。
```

## 封面图

- 主体明确：一个人、一个物体或一个对比场景。
- 留白：右侧或上方留出标题空间。
- 颜色：与公众号整体视觉一致；不要超过三种主色。
- 情绪：与文章一致；干货用冷静，故事用温暖，锐评用对比强。
- 禁止：真实名人肖像、品牌 logo、政治符号、医疗效果承诺。

## 正文信息图

- 一张图只讲一个观点；不要把整篇文章塞进一张图。
- 用 2–5 个步骤、对比项或图标表达。
- 文字尽量少；如果必须带文字，给出简短中文标签。
- 尺寸 1:1 或 4:3；手机端可读。

## 结尾引导图

- 一个动作：关注、收藏、留言、预约。
- 画面简洁，不要堆二维码、联系方式、夸张承诺。
- 不要伪造“限时”“最后一天”等紧迫感。

## 通用禁止项

- 不要真实人物面部特写或可识别人物。
- 不要品牌 logo、商标、版权角色。
- 不要政治符号、国旗、领导人形象。
- 不要医疗、法律、投资收益的保证性画面。
- 不要低俗、暴力、歧视性内容。
- 不要生成带大段文字的图；文字后期排版更可控。

## 质量检查

- [ ] 封面能在手机列表页看清主体。
- [ ] 信息图每张只有一个中心。
- [ ] 颜色与文章风格一致。
- [ ] 没有真实人物、品牌、政治符号。
- [ ] 没有大段文字或错误中文。
- [ ] 图片尺寸符合公众号排版要求。
